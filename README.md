# Siegfried Urban MAFO Service – Landingpage

Moderne, responsive One-Page-Webseite für **Siegfried Urban MAFO Service** mit Fokus auf Markt- und Sozialforschung.

## Inhalte

- Hero-Bereich mit klarem Nutzenversprechen
- Leistungsübersicht (Beratung/Konzeption, Datenerhebung, Auswertung/Reporting)
- Strukturierter Projektablauf
- Kurzprofil und Kontakt-Call-to-Action

## Lokal starten

```bash
cd /workspace/spongerepo
python3 -m http.server 8000
```

Dann im Browser öffnen:

- http://localhost:8000/
